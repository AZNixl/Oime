# ○输入法 · Oime

**Android RIME 输入法** —— librime 引擎 + Jetpack Compose 声明式键盘（键面、图标与 ○ 圆环为手绘），方案组零拷贝架构，支持本地语音识别。

> 由 AZime 更名而来（应用 ID 现为 `com.oime.input`，可与旧版并存）。
> 当前版本 **1.0.0（vc102）** · 最低 **Android 5.0（minSdk 21）** · **arm64-v8a + armeabi-v7a**
> · 最新安装包见 **[Releases](https://github.com/AZNixl/Oime/releases/latest)**
>
> **开发方式**：本项目从架构设计、功能实现、界面改造到文档与 CI 排障，**全程由 AI 协作完成**
> （AI 生成代码与文档，人工负责需求、调参与验收）。AI 在实现过程中参考的上游项目见文末「借鉴与引用」。

## ○ 圆环

工具栏正中那颗 **○ 圆环**，灵感来自 **BlackBerry 的轨迹球（Trackball）与光学触摸板（Optical Trackpad）**。

那是手机史上最有辨识度的拇指交互之一：一颗小球（后来是一片光学小板）嵌在机身里，拇指在上面搓动，光标就跟着走；按一下是确认，长按呼出菜单。BlackBerry 的经典操作几乎都是从这颗小球展开的。

○ 输入法把它做成屏幕上的**一颗环**：球体在动，手指的落点不动（像拇指搓轨迹球那样"拨"），于是一个可点击、可长按、可四向拨动、还能上下滑的控件就成型了。

**它的手势与对应的轨迹球习惯：**

- **点击** —— 呼出 ○ 菜单
- **长按** —— 语音输入
- **左右拖动** —— 移动光标
- **下滑** —— 收起键盘
- **上滑** —— 快捷应用悬浮栏：5 个应用槽位，滑动选择、松手启动，下滑取消

**圆环有三种形态**（设置 → O 圆环）：

- **圆形环** —— 呼吸环（默认），颜色随主题深浅自适应
- **圆角方形环** —— 方形描边，硬朗
- **眼睛** —— 环内一双眼睛，会随机做表情：眨眼、连眨两下、左右看、上下看、眯眼、惊讶、困倦、笑眼、转圈看、生气，共十套动作，间隔 2~9 秒随机出现

## 界面风格：三种，随时切换

设置 → 主题与配色里是一个下拉栏，**选中即生效**（键盘与设置页一起变）：

> 目前提供 **Material / Miuix / One UI** 三种（原 iOS / Nothing OS / Material You 因键面与底色对比
> 始终不理想已移除）。三种都做了**对比度兜底**，任何风格下键面与文字都保证可辨 ✓

- **Material** —— 中性灰 + 白键，最朴素的底色
- **Miuix** —— MIUI 风格扁平：页面浅灰、卡片纯白、工具栏纯白
- **One UI** —— 大圆角 + 键面柔和阴影 + 半粗字重
- **iOS / 胶囊** —— 大圆角、无描边、细字重，轻盈
- **Nothing OS** —— 单色黑白 + 细描边 + 等宽字体
- **Material You** —— 从系统壁纸动态取色（Android 12+，低版本自动回落到 Material）

风格只改**视觉**（配色、描边、阴影、字重、字体），**不动你亲手调好的键高、行距、圆角**。想要整套风格连几何一起换，可以打开「几何也跟随风格」。

配色本身也开放：**字母键**（26 字母 + 逗号句号共享一色）、**功能键**（Shift / 符号 / 退格共享一色）、**强调键**（回车与高亮），亮色与暗色各存一套。取色用调色板 + 十六进制 + 透明度滑杆。默认按**原色**呈现，“被半透明冲淡的柔和观感”需要主动关闭原色开关。

## 键盘与布局

- **主键盘四选一**：26 键（默认）、**九键**（T9 数字键盘，键面标字母组）、**十四键**、**十七键**（后两者是字母分组键盘：**点击出第一个字母，长按或上滑出第二个字母**，自带双字母机制，不依赖输入方案）
- **其他键盘页**：九宫格数字、26 键符号、全部符号（分类网格，含「中文符号 / 英文符号」）、emoji
- **横屏自适应**：沿用同一套布局，只把键高限低 25%，避免横屏时键盘占掉大半个屏幕
- **键盘编辑器**：可视化网格编辑，标签 / code / 宽度 / 高度系数 / 长按 / 上下左右四向滑动 / 角标提示，可增删键与行；编辑器里附**内置功能键值清单**
- **长按一个字段管两件事**：填单个动作或符号就直接执行；空格分隔多个则是长按气泡
- **符号随中英切换**：键面长按符号与长按气泡会在中文标点与 ASCII 之间自动切换（h→`_`、m→`:`、`,`→`!`、`.`→`?`、k→ASCII 括号）
- **空格**：长按**连续输入空格**（和电脑空格键一样），**上滑切换中英**
- **单手模式**（键盘缩到一侧）与**悬浮模式**（键盘缩小、可整体拖动）
- **工具栏工具**默认不显示，自行勾选：剪贴板、方案、数字、emoji、符号、设置、语音、收起、中英、撤回、重做、单手、悬浮

## 按键手势

- 四向滑动直出符号；长按弹出符号气泡，气泡内可滑动选择，多行气泡支持上滑换行
- 退格左滑选择删除、上滑全清、下滑撤回（操作栈：插入可删、删除可恢复）
- 键面四向提示按字面方向显示；长按提示在右上角
- 括号类符号上屏后**光标自动停在括号中间**（`{text}{Left}` 语法，用 `setSelection` 实现）
- 振动与音效统一在**按下瞬间**触发，三个键盘页手感一致

## RIME 引擎

- librime（`librime_jni.so`）+ **方案组架构**：组目录即 librime 的 user 数据目录，零拷贝加载
- 方案组切换、ZIP / SAF 文件夹导入、方案重命名、导入后全量部署
- 候选横滚 + 数字前缀选词 + **更多候选网格面板**（◀▶ 翻页）；面板里每个候选的注释（**拆字 / 拼音**）显示在字的上方，背景随文字长度伸缩
- 方案切换：工具栏「方案」按钮 → 键盘下方中间的横向悬浮栏，点一下即切
- **拆字与缺字兜底**：字体回退链末尾追加系统字体，自定义字体缺部首字形（如 ⺮ 龸 亻）时不再出现豆腐块
- **输入框类型自动切页**：数字与电话框自动切九宫格；密码、邮箱、网址框自动切英文；回到普通文本框**自动恢复中文**（只恢复它自己切过去的那一次，不干扰你手动切换）

## 语音输入：三个引擎可选

- **SenseVoice（离线）** —— 本地 int8 模型，中 / 英 / 日 / 韩 / 粤，松手出全文
- **流式 zipformer（离线）** —— 边说边出字
- **联网 API** —— 任意 OpenAI 兼容的 `/v1/audio/transcriptions`，自填地址、密钥与模型

模型侧载在 `Documents/Oime/models/`，缺模型时按键给出提示而不是崩溃。语音识别可选用的联网服务商（含豆包 / 火山引擎的接入方式与限制）见 [DOUBAO_ASR_REPORT.md](DOUBAO_ASR_REPORT.md)。

## 剪贴板中心

剪贴板历史与收藏短语双选项卡、卡片列表、︙ 菜单（收藏 / 置顶 / 分词 / 删除 / 全清）。

复制之后工具栏常驻一条**复制条**：**点击内容上屏**，**右侧 ✕ 消亡**（消亡时震动提示）。不用先上屏就能清掉强制复制的无效内容，打字过程不会让它消失。可在设置里整体关闭——关闭后不再监听剪贴板。

> 长文本上屏用的是完整文本，显示才做截断；复制新内容永远会重新出现（上屏或消亡过的条目不会自己冒出来）。

## 悬浮窗（编码预览）

跟随光标显示（`requestCursorUpdates` + `CursorAnchorInfo`）：悬浮窗里给出输入码前几码与候选，余下的码仍在工具栏。

可调项：背景色（取色板，默认跟随主题）、**首选候选加强调底色**、**显示候选数量**、**候选横向或竖向排列**、位置、字号、背景不透明度。

## 音效

打字音效默认关闭。打开后从**外置文件夹**读取，目录是 `Documents/Oime/sounds/`（安装后自动创建），支持 mp3 / ogg / wav / m4a。

目录里已经放了一份**内置默认音效 `click.ogg`**，所以打开开关即可出声；想换音效把自己的文件丢进这个目录，在设置里试听、选择、调音量。同名文件不会被覆盖，替换后也不会被还原。关闭时热路径零开销。

## 内置功能（动作键值）

按键动作用**内置功能键值**，命名对齐 RIME：

- 编辑：`select_all`、`cut`、`copy`、`paste`、`undo`、`delete_all`
- 上屏：`newline`（同 `return` / `enter`）、`space`、`tab`、`backspace`、`delete`
- 中英：`toggle_ascii`（同 `ascii_mode`）、`caps_lock`、`shift`
- 光标：`left`、`right`、`up`、`down`、`home`、`end`
- 翻页：`prior`（同 `page_up`）、`next`（同 `page_down`）
- 组合：`esc`（同 `escape`）、`clear`
- 页面：`page:main`、`page:symbols`、`page:numpad`、`page:emoji`
- Oime 内置：`deploy`、`switch_ime`、`clipboard`、`menu`

大小写、连字符、下划线都容错；不认识的写法按**字面文本**上屏（支持 `{Left}` / `{Right}` 光标后缀）。完整清单也印在键盘编辑器里。

## 构建

仓库是**公开仓库**，构建全部交给 GitHub Actions，本机只做语法与类型校验：

```bash
./gradlew compileDebugKotlin     # 本机校验，不出包
```

推送到 `main` 后，Actions 会自动出包。**开发期安装包**：仓库 Actions → 最新一次 run → 产物 `app-debug`（下载需登录 GitHub）；正式版会发布到 Releases。语音依赖 `sherpa-onnx-1.13.5.aar`（约 49MB）不入库，CI 在构建前从官方 release 下载到 `app/libs/`。

- 技术栈：Kotlin 1.9.22 / AGP 8.3.0 / Gradle 8.4 / Compose BOM 2024.02.00 / JDK 17
- 引擎：`librime_jni.so`（arm64-v8a）；方案导入用 zip4j
- 项目路径含非 ASCII 字符时，需要 `gradle.properties` 里的 `android.overridePathCheck=true`

## 隐私说明

- **默认不联网**：敲字、联想、方案与剪贴板全在本地完成，除非你主动选择「联网 API」语音引擎并自行填写地址与密钥。
- **剪贴板**：复制条与剪贴板历史只在本机读写，不上传；可以在设置里整体关闭，关闭后不再监听剪贴板。
- **语音**：默认可选两个**离线**引擎（模型放在 `Documents/Oime/models/`），全程不出本机。
- **日志**：诊断日志只写在本机 `Download/oime_diag.log`，不会自动外发。
- **权限**：除输入法本身所需（读取剪贴板、振动、录音、读写外置目录）外，`QUERY_ALL_PACKAGES` 仅用于 ○ 圆环的上滑快捷启动列表。

## 下载与安装（发行版）

到 **[Releases](https://github.com/AZNixl/Oime/releases/latest)** 按 CPU 架构下载对应包（**分开打包，只装一个**）：

| 文件 | 适用 |
|---|---|
| `oime-<版本>-arm64-v8a.apk` | 绝大多数手机（2016 年后的 64 位机型）|


> 若提示「应用未安装 / 不兼容」，说明你的设备是 32 位（armeabi-v7a）—— 目前暂不发布该架构。
> x86 / x86_64（模拟器、极少数平板）暂不发布。

1. 下载对应架构的 APK → 安装（系统可能提示"未知来源"，允许即可）
2. 打开 **○输入法** App → 按引导启用并切换输入法
3. 首次启动会在 `Documents/Oime/` 下自动建立目录：

```
Documents/Oime/
├── schemas/     输入方案（虎码 / 双拼 / 白霜…，可直接往里放目录）
├── models/      语音模型（sense-voice / zipformer，需自行下载）
├── fonts/       键盘字体（放 .ttf / .otf 即可在设置里选）
├── sounds/      按键音效
├── backup/      设置备份（JSON）
└── logs/        运行日志（按天分文件，自动保留 7 天）
```

## 兼容性

| 项 | 支持 |
|---|---|
| **系统** | **Android 5.0+**（minSdk 21，targetSdk 34）|
| **CPU** | **arm64-v8a** ✓（64 位 ARM，2016 年后的机型；**当前只发布这一种**）<br>armeabi-v7a / x86 / x86_64 —— **暂不发布** |
| 屏幕 | 竖屏 / 横屏（横屏为分体布局）|

> **关于 ABI**：输入核心 `librime_jni.so` 取自 **Xime v2.6.2** 的官方 release（arm64-v8a 与 armeabi-v7a
> 两个版本，同一版本号保证 JNI 接口一致 ✓）。
> 构建脚本**按 `app/src/main/jniLibs/` 实际内容自适应**：放入哪个 ABI 就打哪个 ✓
> （x86 / x86_64 暂无设备测试，故不发布 ✓）

## 隐私与权限

- **不采集任何输入内容、设备标识，无统计/遥测 SDK**；数据全部在 `Documents/Oime/`，只存在本机
- 权限用途：**录音**（仅长按 ○ 键听写时）、**存储/使用情况**（读写 `Documents/Oime/`）、
  **网络**（仅在你主动操作时：打开链接 / 自填的联网语音 API / 手动下载方案）
- 详细条款见 App 内 **设置 → 关于 → 隐私条约**；开源组件与许可见 **关于 → 开源许可**

## 日志（排查问题用）

- 位置：`Documents/Oime/logs/oime-YYYY-MM-DD.log`（崩溃另有 `crash-YYYY-MM-DD.log`，含设备信息）
- **默认只记错误 / 警告 / 关键事件**（几乎不耗电）；
  需要详细埋点（按键/候选/光标）时到 **设置 → 关于 → 日志 → 详细日志** 打开即可 ✓

## Fork 后如何跑 CI（已验证无私有依赖）

本仓库的 CI 只依赖**公开资源**，fork 后无需任何配置即可直接跑：

- 工作流：`.github/workflows/android.yml`（push main/develop、PR、也可手动 `workflow_dispatch`）
- **无 secrets / 无私有 token / 无仓库硬编码**（不校验 owner/repo）
- JDK 17（temurin）+ 标准 Android SDK（ubuntu-latest 自带）
- `sherpa-onnx-1.13.5.aar`（约 49MB，超 GitHub API 单文件限制）**不入库**，
  由 CI 从官方 release 下载（公开 URL）
- `librime_jni.so`、RIME 资源、内置音效等**都在仓库内**，无需额外准备
- 产物：`app-debug` 工件（保留 3 天），路径 `app/build/outputs/apk/debug/app-debug.apk`

**唯一注意**：`cache: gradle` 对 **public 仓库免费**；若你的 fork 是 **private**，
Gradle 缓存会占用 500MB 存储额度（历史上曾因此导致上传步骤失败），
可把 `setup-java` 的 `cache: gradle` 一行删掉再跑。

本地构建（可选）：在仓库根目录执行 `./gradlew assembleDebug` 即可，
`local.properties` 中的 SDK 路径请按自己的机器填写（该文件不入库）。
